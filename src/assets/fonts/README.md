# Manrope

Fonte variável usada no tema da aplicação, com pesos de 200 a 800 e subconjunto latino com suporte ao português. O arquivo WOFF2 é servido localmente pelo `@next/font/local`.

- Origem: [Google Fonts](https://fonts.google.com/specimen/Manrope).
- Licença: SIL Open Font License 1.1, incluída em `Manrope-OFL.txt`.
